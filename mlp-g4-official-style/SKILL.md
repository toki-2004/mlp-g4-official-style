# 小马绘画

MLP G4 / Friendship is Magic 同人绘画与图像编辑的统一入口。兼容旧称 `mlp-g4-official-style`；用户说“按小马绘画来”“按 G4 官方风格”均按本 Skill 执行。

## 0. 优先级与分层

验收优先级（判断一张图能不能用）：

1. **P0** 形体、解剖、拓扑、数量关系、承重与重心正确
2. **P1** 角色身份、物种特征、所选画风一致
3. **P2** 光影、服装、道具、背景、装饰

P0 错误不能用画风或光影弥补，直接判 **REJECTED**。数量类错误、前蹄结构错误、翅根或翼数量错误、关节反向、穿模、身体断裂都属 P0，判据见 L0 与 L1。

知识分层（决定读哪个文件；L 表示层，P 表示验收优先级，两者无关）：

- **L0 小马基本形体**：`references/body-base.md`
- **L1 绘画基本流程**：`references/drawing-process.md`
- **L2 画风模块**：`references/styles/`
- **L3 角色库**：`references/characters/`

## 1. 读取纪律

只读本次任务真正需要的文件，不要一次全读：

- 任何小马绘画都先读 L0。
- 需要完整流程、骨架、光影、迭代规则时读 L1。
- 用户指定画风时读对应 L2 模块；不指定则默认 G4 官方风格。
- 出现具名角色时读其 L3 条目。
- 只做局部修改时同样按此顺序读，并先看 L1 的“局部最小修改”。

## 2. 工作流

1. 确认需求：角色、画风、构图、画幅、动作、用户明确要求。
2. 读 L0，锁定形体规则。
3. 按 L1 阶段推进：反 AI 味参数卡 → 构图 → 骨架 → 体块 → 结构自检 → 线稿与光影 → 细节 → 验收。
4. 具名角色读 L3，套用身份常量与其对应画风子条目。
5. 画风由 L2 唯一确定。
6. 出图后按 L1 的固定格式给自检输出；P0 不过就不进入细节迭代。

## 3. 画风隔离

- 一个 L2 模块只描述一种画风。跨画风混搭默认不执行；用户明确要求时才执行，并显式说明哪部分属于哪个画风。
- 身份常量（体色、眼色、鬃毛主色与轮廓、Cutie Mark、物种、角翼）来自 L3，不随画风改变；画风只改线条语言、材质、装饰、氛围。
- 画风模块不得覆盖 L0 的形体规则。
- **发型轮廓**与**发色**是两个独立维度。角色 A Cos 角色 B 时只改用户指定的维度，默认不替换 A 的身份色；Cos 不是变身。

## 4. 生成前检查

1. 这是谁？身份常量对不对？
2. 是 Cos 还是变身？发型轮廓和发色有没有混？
3. 几条腿？几只翅膀？几只角？
4. 前蹄结构对不对？两条前腿来源是否清楚？
5. 哪几条腿承重？重心落在支撑面内吗？
6. 飞马的两翼翼根是否都在肩背？
7. 当前参考图是否已被标记 REJECTED？
8. 用户是否要求“只改一点”？
9. L1 的反 AI 味参数卡六项（机位与裁切、线宽表、明度阶梯与最暗点、对比度分配、背景元素清单、材质对比）是否已填完？

## 5. 失败处理

发现 P0 错误或用户已否定该图时，立即停止在当前图上叠加细节，回退到最近结构正确的版本或换干净母版重新生成。不要修补错误母版。

## 6. 交付

每次生成后按 L1 的固定格式给 5 行自检输出（计数、身份、结构、反 AI 味、判定）。具体格式与判据见 `references/drawing-process.md`。
