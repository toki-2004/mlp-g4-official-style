# L1 绘画基本流程

从零生成或大幅修改一张小马图时，按本文阶段推进。结构规则不在此复述，判据见 L0 `body-base.md`。阶段顺序不可跳：上一阶段没定完，不进下一阶段。

阶段总览：需求取材 → **反 AI 味参数卡** → 构图镜头 → 骨架 → 体块 → **结构自检 Gate** → 线稿与光影 → 细节 → 验收。

## 阶段 0 · 需求与取材

1. 记下：角色、物种、画风、画幅与比例、镜头、动作、场景、用户明确要求与禁忌。
2. 读 L0（必读）。
3. 读 L2 对应画风模块；用户未指定则用 `styles/g4-official.md`。
4. 有具名角色时读 L3 条目，抄下身份常量。
5. 检查参考图状态（见“参考图状态”一节），REJECTED 的图不得作为母版或参考。
6. 用户要求“只改一点”时直接跳到“局部最小修改”。
7. 填“反 AI 味参数卡”（下一节），六项全部写成具体值，再进阶段 1。

## 反 AI 味参数卡（阶段 0 必填）

这六项在动笔前定死，并原样写进提示词（见附录 A）。它们是正向执行参数：定了就不会长出 AI 味，不定就一定会。

1. **机位与裁切**：从下列里选一组写下来——① 偏心 1/3 站位；② 前景元素压边；③ 局部出画（切脚、切翅尖、切尾巴）；④ 过肩；⑤ 俯视；⑥ 仰视；⑦ 中景切脚。默认解“正面居中 + 全身完整”不选。
2. **线宽表**：按画面短边取比例——外轮廓 = 短边 × 0.4%，内部结构线 = 短边 × 0.25%，细节线 = 短边 × 0.15%，三者至少相差 1.5 倍。例：1448×1086 的图约 4px / 2.7px / 1.6px。
3. **明度阶梯**：定三档并写下来——最暗点 ≤ 25%、固有色 45%–70%、亮部 ≥ 85%；同时写明最暗点落在哪一处：翅下 / 下颌 / 落地投影 / 服装深处（四选一）。
4. **对比度分配**：写下一个焦点区（对比度最高）、一到两个次级区、其余为简化区（对比度最低），并写明焦点落在画面什么位置。
5. **背景元素清单**：最多 3 个，逐个写出来；清单以外的地方用色块与留白。
6. **材质对比**：从哑光、半光泽、柔透、硬高光里选至少 3 种，分配到身体、金属、布料、鬃毛、蹄上。

## 阶段 1 · 构图与镜头

- 按参数卡第 1 项先定机位与裁切，再往画布上放主体。
- 按参数卡第 4 项落焦点：焦点通常不压正中，焦点所在区域保留细节，其余区域提前判定为简化区。
- 定画幅（横/竖/方）与主体在画面中的位置；角色视线方向要留出视线空间。
- 定镜头高度：平视、俯视、仰视。镜头高度决定躯干与四肢的透视关系，先定镜头再画身体。
- 定动作幅度与画面重心；大幅动作要预留四肢与翅膀的展开空间。
- 按参数卡第 5 项摆放背景元素，只放清单里的，其余留给色块与留白。
- 多角色时先排前后层次与遮挡关系，避免角色重叠导致肢体融合。

## 阶段 2 · 骨架

先搭骨架，不画外观：

1. 画躯干轴线（脊柱弧线），确定头、颈、胸、臀在一条可解释的曲线上。
2. 标出四条腿的关节球：前腿肩→肘→蹄，后腿髋→膝→蹄；位置定完再连成腿。
3. 定承重腿（站立至少两条，飞姿除外），把重心投影落在支撑面内。
4. 飞马：标出两侧肩胛位置，作为翅根锚点（翅根规则见 L0 §7）。
5. 独角兽与天角兽：标出额角根部，确认在额头正中线。
6. 标出尾巴根部。

骨架阶段的自检：轴线不断裂、关节方向一致、前后腿来源清楚、前腿长度受控（见 L0 §4 前蹄专条）。

## 阶段 3 · 体块

- 按骨架加厚成体块：头、颈、躯干、四条腿的圆柱/锥形、蹄、尾根。此阶段只求比例与拓扑正确。
- 飞马：先做翼根 + 主翼骨走向，再叠羽片；先定开合程度再画羽毛（顺序见 L0 §7）。
- 不在此阶段加睫毛、饰品、花纹、背景细节。

## 阶段 4 · 结构自检 Gate

逐项核对，任何一项不过就回到阶段 2 或 3，不进入上色：

1. 计数：1 头、1 躯干、4 腿、1 尾，物种结构数量正确。
2. 前蹄专检：按 L0 §4 的前蹄专条逐条过，重点确认无手指、无额外腕肘、两条前腿来源分开。
3. 承重与重心：承重腿明确，重心在支撑面内，无前栽。
4. 飞马双翼专检：按 L0 §7 核对翅根位置、双翼配对、收展逻辑、羽片穿模。
5. 身份常量：体色、眼色、鬃毛色、Cutie Mark、物种是否与 L3 一致。
6. P0 判据总表：见 L0 §11，任一命中即 REJECTED，回退重做。

## 阶段 5 · 线稿与光影

### 5.1 线稿

- 按参数卡第 2 项的线宽表起稿：外轮廓最粗、体块转折次之、细节线最细，三类线的实际宽度对得上比例。
- 线宽随画面尺寸换算，不照搬像素值；画面越大，线宽按短边比例同步放大。
- 线条语言（粗细变化、有无断线、是否勾边）由 L2 画风决定。

### 5.2 固有色

- 按参数卡第 3 项的三档明度铺色：固有色落在 45%–70% 这一档，再叠加环境色；固有色不因环境光改变色相。

### 5.3 主光

- 全图只有一个主光方向（如左前上、右后上）。确定后所有物体——角色、翅膀、饰品、背景——受光方向必须一致。
- 主光高度决定投影长度：光越平，投影越长。

### 5.4 明暗交界线

- 沿体块转折走，不跟随外轮廓描边；圆柱形的腿与颈部是弧线，块面形的头与臀是折线。
- 明暗交界线是最暗的起点，往暗部方向逐渐被环境光抬亮。
- 按参数卡第 3 项把最暗点压到位（≤ 25% 明度），落在参数卡指定的位置上。

### 5.5 投影

- 投影方向与主光方向一致；落地投影的形状由承重腿与地面接触点决定，贴住承重面。
- 角色遮挡部分形成自投影（如头在颈上的投影、翅膀在躯干上的投影），翅下、腹部、下颌下方必须有压暗。

### 5.6 环境光与反射光

- 暗部不能死黑：用环境光与地面反射光把暗部抬亮，保持体积可读。
- 抬暗部时保留已经落位的最暗点，不要整体抬到中间调；中间调占比越高，画面越平。
- 亮部与暗部的冷暖要统一：亮部偏暖则暗部偏冷（或反之），整张图不逐物体翻转。

### 5.7 边缘光

- 用于把角色从背景中剥离，方向跟随主光；不要四面都加边缘光。

### 5.8 材质

- 鬃毛与尾巴：先块面、再层叠，高光条带沿发流方向走；不画写实散发丝（写实程度由 L2 界定）。
- 金属与宝石：硬高光 + 清晰反射，高光位置与主光一致，不叠加柔和散射。
- 布料：按褶皱走向上明暗，褶皱走向跟随身体的支撑点。
- 蹄：整体哑光，脚底与承重面接触处加深。

### 5.9 分级与笔触

- 先铺硬边色块，边界清楚；再在体积转折处做柔和过渡，全图柔和过渡不超过 3 处。
- 明暗分级数量、笔触质感、是否描边由 L2 画风唯一决定。

## 阶段 6 · 细节

顺序：睫毛与表情 → 鬃毛分区与轮廓 → 饰品 → 服装与道具 → 背景。

- 细节量按 主体 70% / 次级角色 20% / 背景 10% 分配；背景先画参数卡第 5 项的清单元素，其余保持色块。
- 睫毛、长发型、艳妆必须在此阶段处理，且仅在 P0 通过后处理（见 L0 §4、§7 的姿势顺序）。
- 表情只改神态，不改身份常量。
- 背景比角色更简化，不抢主体；背景的复杂程度由 L2 界定。
- 到此阶段若发现 P0 问题，停止加细节，回阶段 4。

## 阶段 7 · 出图后验收

1. 看整体轮廓与剪影，确认结构在缩略图下依然读得出来。
2. 按阶段 4 的 Gate 逐项复核。
3. 跑反 AI 味检查（P1，不触发 REJECTED，但要在自检输出里给结论）：线宽是否按参数卡分层、最暗点是否落在指定位置、焦点区对比度是否高于简化区、柔和过渡是否不超过 3 处、背景是否只出现清单里的元素且细节少于主体。
4. 按附录 C 给固定 4 行自检输出。
5. 判定为 REJECTED 时，按“回退策略”处理，不修补错误母版。

## 局部最小修改

触发条件：用户说“大体没问题，只改……”“唯一的问题是……”“其它不要动……”。

做法：

1. 先列出已锁定、不允许改变的部分（构图、身份常量、画风、姿势、光影方向）。
2. 只修改用户指出的问题区域或属性。
3. 只有当 X 属于 P0 结构问题时，才允许必要的局部联动修改；不允许趁机重设计整张图。
4. 修改后重新跑阶段 4 的 Gate。

## 参考图状态

- **REJECTED**：用户明确否定该图（“失败”“不要用这张”等）。本会话与本项目内不再作为母版、结构参考、风格参考或继续迭代的基础。若仅某个外观方向被认可而结构被否定，只保留被认可的设计原则，不把那图当结构参考。
- **FINISHED**：用户说“可以”“成品图”。可作为同系列后续作品的合格参考；用户要求局部修改时，其它已确认区域全部锁定。
- **GOLD**：只有用户明确指定为最高级母版时才使用。
- 状态只在本会话与本项目内有效，不跨会话自动继承；用户要恢复某张被否定的图时必须明确说明。

## 多角色场景

- 每个角色各自满足 L0 的全部形体规则，只是简化程度随景深变化。
- 中景与远景角色可以简化细节，但腿数、物种结构、翅膀数量仍必须正确。
- 主角的身份常量必须完整，次要角色至少保留体色、鬃毛轮廓与物种。
- 不因画面拥挤出现肢体融合、共享腿、重复角色部件。
- 各角色的主光方向必须一致。

## 回退策略

出现 P0 错误或用户否定时，按以下顺序选择：回退到最近结构正确的版本 → 换干净母版 → 用更简单的姿势与构图重新生成。不回修补错误母版，也不靠叠加细节掩盖结构问题。

## 附录 A · 生成提示词骨架

拼提示词时按以下五句组合，不要只写情绪词：

1. 计数句：明确角色数、物种、腿数、翼数、角数（例：一匹飞马，四条腿，一对翅膀，无角）。
2. 结构句：躯干轴线方向、承重腿、翅根位于肩背、前蹄为单一蹄面且无手指。
3. 身份句：体色、眼色、鬃毛与尾巴配色轮廓、Cutie Mark 位置与图案（照抄 L3 的身份常量）。
4. 画风句：由 L2 模块给出（线条、上色、材质、氛围）。
5. 画面句：画幅、镜头高度、动作、背景、主光方向。
6. 参数卡句：把阶段 0 的六项原样落成文字，例如“偏心 1/3 构图，前蹄切出画外，外轮廓线约为画面短边的 0.4%，最暗点在翅下，焦点在左眼与肩部，背景只有灯笼与月亮两个元素，金属半光泽＋鬃毛柔透＋身体哑光”。参数卡句写在画风句之后、画面句之前。

只改局部时，在骨架里显式写出“其余部分保持不变”以及已锁定项。

## 附录 C · 固定自检输出

每次出图后输出 5 行，便于用户核对：

```
计数：头 1 / 躯干 1 / 腿 4 / 尾 1 / 翼 <n> / 角 <n>
身份：体色 <是/否> / 眼色 <是/否> / 鬃毛色 <是/否> / Cutie Mark <是/否>
结构：前蹄 <通过/不通过> / 承重与重心 <通过/不通过> / 翅根与双翼 <通过/不通过> / 穿模 <无/有>
反 AI 味：线宽分层 <是/否> / 最暗点落位 <是/否> / 焦点对比 <是/否> / 柔和过渡处数 <n> / 背景元素 <n 个>
判定：<通过 / REJECTED（原因）>，下一步 <细化 / 回退重做>
```
